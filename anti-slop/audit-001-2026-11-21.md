# Anti-Slop Audit 001 — Dashboard Admin CBT

Tanggal: 2026-11-21
Mode: AFTER (session override)
Scope: `app/dashboard/**` + komponen yang dipakai halaman dashboard admin (`/root/cbtapp`)
Metode: inspeksi kode (grep/JSX), build `npm run build`, curl produksi. Belum ada uji klik per kontrol atau inspeksi visual di perangkat.

## Temuan

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

### HIGH

1. **[R-03] HIGH** — `components/pdf-access-card.tsx:146` — tabel masih `overflow-hidden rounded-lg border` (tidak `hidden … md:block`), padahal daftar kartu `md:hidden` ada di baris 246. Di ponsel tabel dan kartu dobel; `overflow-hidden` memotong konten.

2. **[R-03] HIGH** — `components/respons-tak-terhubung-card.tsx:88` — tabel 7 kolom dibungkus `overflow-x-auto` tanpa state kartu mobile; dipakai `/dashboard/hasil/page.tsx:158`. Horizontal scroll leak di ponsel.

3. **[R-03] HIGH** — target sentuh di bawah 44px pada kontrol yang masih tampil di ponsel: `components/ruangan-management-card.tsx:109,112` (`size-8`), `components/question-bank-row-actions.tsx:115,125,137,145`, `components/subject-row-actions.tsx:98`, `components/guru-analisis-button.tsx:49`, `components/progress-detail-dialog.tsx:57` (trigger), `components/exam-schedule-status-switch.tsx:44` (Switch default 36x20), dan `SelectTrigger` pagination `h-8` di 6 kartu manajemen (`classroom`, `pdf-access`, `progress`, `question-bank`, `student`, `subject`, `teacher`, `user`). Tombol di dalam tabel `hidden md:block` dikecualikan.

4. **[R-03] HIGH** — semua tabel memakai dua state saja: `hidden … md:block` + daftar `md:hidden`. Pada lebar 768–1024px tabel 6–7 kolom langsung dipadatkan (pola Two-State Layout). Tidak ada state antara/tablet yang dirancang.

5. **[R-27] HIGH** — tidak ada `app/dashboard/**/loading.tsx` maupun `error.tsx`; hanya empty state (18 file) dan `error &&` untuk kegagalan mutation. Fetch/error awal tidak punya tampilan khusus.

6. **[R-02] HIGH** — `components/hasil-table-card.tsx:262` masih memakai karakter em dash `—` sebagai legenda "tidak dijawab". R-02 melarang em dash di teks UI tanpa pengecualian untuk simbol legenda.

7. **[R-35] HIGH [CONFIRM]** — belum ada catatan click-through element-by-element; yang terverifikasi baru `tsc`, `npm run build`, dan HTTP 200/307 produksi. Klaim PASS interaksi dan kontras (R-25) belum bisa diberikan.

### MEDIUM

8. **[R-31/R-20] MEDIUM** — `DESIGN.md` masih menetapkan palet hijau tua + biru + amber, sedangkan `app/globals.css:97` memakai `--primary` lime sesuai permintaan terbaru. Arah desain tertulis sudah tertinggal dari implementasi, sehingga alasan keputusan warna tidak konsisten.

9. **[R-12] MEDIUM** — `shadow-sm` dipakai sebagai default pada hampir semua kartu mobile (9 komponen manajemen + jadwal/hasil/progres), tanpa alasan elevasi yang ditulis. Bayangan jadi gaya generik, bukan penanda hierarki.

10. **[R-39] MEDIUM** — `aria-hidden` hanya 18 pemakaian dibanding ~255 pemakaian ikon di dashboard/komponen; aturan `cursor: pointer` juga tidak ditemukan di `app/globals.css` maupun `components/ui/button.tsx` (R-39 meminta keduanya di base layer). Tombol ikon sebagian besar sudah punya `sr-only`, ini baik.

### LOW

11. **[R-11] LOW** — `DESIGN.md` menetapkan `rounded-sm` untuk semua elemen, tetapi ada 57 pemakaian `rounded-lg` berdampingan dengan 101 `rounded-sm` di halaman dashboard/komponen. Radius tidak konsisten dengan sistem yang ditulis.

## Yang sudah lolos (berdasarkan inspeksi kode)

- R-03: 12 tabel utama sudah punya state kartu mobile (`dashboard`, `jurusan`, `bank soal`, `peserta`, `kelas`, `mapel`, `jurusan`, `guru`, `user`, `jadwal`, `hasil`, `pengerjaan`), kecuali dua temuan di atas.
- R-26: tombol aksi utama punya `onClick`/`href` nyata; tidak ada tombol mati yang ketemu.
- R-16/R-15: tidak ada buzzword AI atau CTA generik ("Get Started", "Learn More").
- R-01/R-10/R-13: tidak ada gradien, glassmorphism, atau glow berlebih di dashboard admin.
- R-23: avatar inisial dipakai sebagai placeholder jujur, bukan foto profil hasil karangan.
