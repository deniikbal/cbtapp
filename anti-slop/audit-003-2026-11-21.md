# Anti-Slop Audit 003 — Dashboard Siswa (`/siswa/dashboard`)

Tanggal: 2026-11-21
Mode: AFTER (session override)
Skills: `antislop` + `antislop-layoutmobile`
Sumber: `app/siswa/dashboard/page.tsx`, `components/student-logout-button.tsx`
Metode: inspeksi kode + browser tanpa sesi. Halaman terautentikasi belum bisa dirender karena vault kosong dan prompt login tidak tersedia; `/siswa/dashboard` tanpa cookie dialihkan ke `/` (terverifikasi di browser 390px).

## Temuan

### HIGH

1. **[R-27] HIGH** — tidak ada `app/siswa/loading.tsx`, `error.tsx`, `app/siswa/dashboard/loading.tsx`, atau `error.tsx`. Empty state tersedia untuk hasil dan jadwal, tetapi tidak ada tampilan loading/error untuk query data siswa, jadwal, dan hasil. Bandingkan dengan dashboard admin yang sudah punya keduanya.

### MEDIUM

2. **[R-03] MEDIUM [CONFIRM]** — `app/siswa/dashboard/page.tsx:174` — teks "Sync terakhir: …" di header tidak punya `truncate` atau `shrink-0`, sedangkan sisi kiri memakai `min-w-0`. Potensi wrap/teks bertabrakan pada 320px belum bisa diukur karena butuh sesi login. Perlu diverifikasi dengan viewport 320px setelah login.

3. **[R-03/R-35] MEDIUM [CONFIRM]** — grid metrik (`grid-cols-2 sm:grid-cols-4`) dan grid info jadwal hanya punya dua state. Antara 640–767px empat kolom dengan label 11px berpotensi padat; belum diukur pada perangkat/tablet nyata. R-35 belum bisa dinyatakan PASS untuk area terautentikasi.

### LOW

4. **[R-25] LOW [CONFIRM]** — teks 11px `text-muted-foreground` dan `text-brand-foreground/85` di header brand belum diukur kontrasnya secara langsung di browser; perkiraan dari token warna masih di atas AA, tetapi perlu verifikasi render nyata.

## Yang lolos (inspeksi kode)

- R-03: tombol aksi ujian `h-11` di ponsel (`sm:h-9` desktop), tombol Keluar `h-11`, progressbar memakai `role="progressbar"` + `aria-valuenow/min/max/label`.
- R-03: `max-w-3xl`, `px-4`, `min-w-0`, `truncate`, dan `line-clamp-2` mencegah teks keluar kartu pada layout data padat.
- R-02: nol em dash di halaman dan komponen terkait.
- R-17: angka metrik berasal dari query DB nyata, bukan statistik rekaan.
- R-26: tombol disabled ("Selesai dikerjakan", "Waktu ujian selesai") menyatakan status, bukan kontrol mati tanpa alasan; aksi Kerjakan/Kirim/Buka lagi punya `form action` nyata.
- R-39: tombol punya teks terlihat, ikon `aria-hidden`, label field tidak relevan di halaman ini.
- R-12/R-04: `border-l-[3px]` pada kartu jadwal menandai ujian ACTIVE, bukan garis dekoratif; ikon BookOpen/Clock3/Flame/Trophy/GraduationCap relevan domain.
- R-01/R-10/R-13: tidak ada gradien, glassmorphism, maupun glow.

## Gate

Belum PASS untuk klaim final: temuan 1 (Hard Gate) perlu diperbaiki; temuan 2–4 perlu verifikasi render dengan akun siswa.
